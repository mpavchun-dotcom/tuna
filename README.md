# Ventra — обновлённая презентация

[Скачать комплект файлов](./Ventra_design_package.zip)

В архиве:
- Обновлённая презентация: 19 слайдов, редактируемый PowerPoint и PDF.
- Библиотека из 9 типовых слайдов: PowerPoint, POTX и PDF.
- Превью и инструкция с замечаниями для проверки данных.

Дизайн: светлые и графитовые фоны, чёрно-белые фотографии, акценты зелёного, оранжевого, жёлтого и красного цветов. Кольца не используются.

Перед внешней отправкой необходимо сверить показатели исходника: на разных слайдах указаны 850+ и 750+ клиентов. Подробности — в README_ru.md внутри архива.
