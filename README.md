В новой версии — 21 слайд, крупная типографика Manrope, контрастные редакционные композиции, исходные монохромные логотипы Ventra без изменений. На обложке — концептуальная фотография, созданная ИИ; это не реальные сотрудники Ventra.

Для точного отображения при редактировании PowerPoint установите Manrope Regular и Bold из полного архива. PDF сохраняет типографику без установки шрифтов.
